How ResearchState Merges Updates Safely

merge_papers_reducer

Used on search_results. Parallel search_worker nodes emit candidate paper lists; this reducer deduplicates and merges them automatically.

operator.add + Skip Cache

Used on paper_contents, paper_analyses, and extracted_evidence. Nodes check existing paper_ids so revision cycles skip redundant downloads and LLM calls.

cp_storage / cp_blobs / cp_writes

SQLiteMemorySaver persists LangGraph memory tables via Python stdlib sqlite3 so interrupted HITL checkpoints survive restarts.
